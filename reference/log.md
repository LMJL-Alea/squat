# QTS Logarithm

This function computes the logarithm of quaternion time series as the
time series of the quaternion logarithms.

## Usage

``` r
# S3 method for class 'qts'
log(x, ...)

# S3 method for class 'qts_sample'
log(x, ...)
```

## Arguments

- x:

  An object of class
  [qts](https://lmjl-alea.github.io/squat/reference/qts.md) or
  [qts_sample](https://lmjl-alea.github.io/squat/reference/qts_sample.md).

- ...:

  Extra arguments to be passed on to next methods.

## Value

An object of the same class as the input argument `x` in which
quaternions have been replaced by their logarithm.
