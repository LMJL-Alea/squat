# QTS Moving Average

This function performs QTS smoothing via moving average.

## Usage

``` r
moving_average(x, window_size = 0)

# S3 method for class 'qts'
moving_average(x, window_size = 0)

# S3 method for class 'qts_sample'
moving_average(x, window_size = 0)
```

## Arguments

- x:

  An object of class
  [`qts`](https://lmjl-alea.github.io/squat/reference/qts.md) or
  [`qts_sample`](https://lmjl-alea.github.io/squat/reference/qts_sample.md).

- window_size:

  An integer value specifying the size of the sliding window used to
  compute the median value. Defaults to `0L`.

## Value

An object of the same class as the input argument `x` storing the
smoothed QTS.
