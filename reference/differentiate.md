# QTS Differentiation

This function computes the first derivative of quaternion time series
with respect to time.

## Usage

``` r
differentiate(x)

# S3 method for class 'qts'
differentiate(x)

# S3 method for class 'qts_sample'
differentiate(x)
```

## Arguments

- x:

  An object of class
  [qts](https://lmjl-alea.github.io/squat/reference/qts.md) or
  [qts_sample](https://lmjl-alea.github.io/squat/reference/qts_sample.md).

## Value

An object of the same class as the input argument `x` in which
quaternions measure the rotation to be applied to transform attitude at
previous time point to attitude at current time point.
